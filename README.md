## 🛠 GitHub 網頁更新操作手冊

如果你不想使用程式碼編輯器，可以直接在 GitHub 網頁上完成網站的日常維護與內容更新。

### 1. 發布新日誌 (New Post)
所有文章都存放在 `content/logs/` 目錄下，格式為 `.md` (Markdown)。

1.  進入倉庫的 `content/logs/` 資料夾。
2.  點擊右上角的 **[Add file]** -> **[Create new file]**。
3.  **命名檔案**：請使用 `YYYY-MM-DD-slug.md` 的格式（例如：`2026-08-03-my-new-post.md`）。
4.  **填寫內容**：複製以下模板並修改：
    ```markdown
    ---
    title: "你的文章標題"
    date: "2026-08-03"
    category: "開發日誌"  # 可選：開發日誌, 思想碎片, 生活記錄, AI 日記
    tags: ["標籤1", "標籤2"]
    ai_diary: false      # 如果是 AI 日記請設為 true
    ---

    這裡開始寫你的正文內容...
    ```
5.  點擊右上角的 **[Commit changes...]** 並確認，網站會自動開始重新部署。

### 2. 修改網站資訊
如果你想修改導航列文字或網站標題：
*   **修改首頁文字**：編輯 `app/page.tsx` 中的文字內容。
*   **修改關於我**：編輯 `app/about/page.tsx`。
*   **修改導航列**：編輯 `components/Nav.tsx`。

### 3. 部署狀態檢查
每次你點擊「Commit changes」後：
1.  GitHub 會通知 Cloudflare Pages。
2.  你可以到 [Cloudflare Pages 控制台](https://dash.cloudflare.com/) 查看 `sungyan-workshop` 專案的建置進度。
3.  大約 1-2 分鐘後，更新就會反映在你的網址上。
