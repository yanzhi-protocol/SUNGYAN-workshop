# SUNGYAN 最新動態媒體

把圖片或影片直接放在這個資料夾，Cloudflare Pages 重新部署後會自動出現在網站的「最新動態」頁面。

## 檔名格式

使用以下格式讓網站取得時間與文案：

```text
YYYY-MM-DD-HH-mm-ss__你的文案.ext
```

例如：

```text
2026-08-27-21-30-00__夜裡的工房.jpg
2026-08-27-20-10-00__今天的測試片段.mp4
```

檔名前半部使用 UTC 時間；網站會由新到舊排列。雙底線 `__` 後面的檔名會成為動態卡片下方的文案，連字號與底線會自動轉成空格。

支援圖片：`.jpg`、`.jpeg`、`.png`、`.webp`、`.gif`

支援影片：`.mp4`、`.webm`、`.mov`

不符合媒體副檔名的檔案會被忽略。若檔名沒有時間前綴，網站會使用 Git 的檔案時間作為排序依據，但建議一律使用標準時間格式。
